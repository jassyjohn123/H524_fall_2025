\section{Part 1: Hypothesis Testing Fundamentals (18 points)}

\subsection*{Question 1: Null Hypothesis Definition (3 points)}

Which statement BEST describes the null hypothesis ($H_0$) in hypothesis testing?

\begin{enumerate}[label=\Alph*)]
\item $H_0$ represents the research hypothesis; it is what we hope to prove through our study
\item $H_0$ represents the alternative explanation; it is always what we want to reject
\item $H_0$ is the hypothesis with the larger p-value; it cannot be proven, only disproven
\item $H_0$ represents the status quo or no effect; it is the hypothesis we assume true until we have sufficient evidence to reject it
\end{enumerate}

\section{Part 2: Type I and Type II Errors (14 points)}

\subsection*{Question 7: Type I Error (3 points)}

What is a Type I error in hypothesis testing?

\begin{enumerate}[label=\Alph*)]
\item Failing to reject the null hypothesis when it is actually false (false negative)
\item Accepting the alternative hypothesis when it is false
\item Rejecting the null hypothesis when it is actually true (false positive)
\item Making a calculation error in computing the test statistic
\end{enumerate}

\vspace{0.5cm}

\subsection*{Question 8: Type II Error (3 points)}

A medical researcher tests a new drug that actually IS effective, but the hypothesis test fails to detect the effect. What type of error has occurred?

\begin{enumerate}[label=\Alph*)]
\item Type I error ($\alpha$); rejected a true null hypothesis
\item Type II error ($\beta$); failed to reject a false null hypothesis
\item Power error; the test was not powerful enough
\item No error; the test correctly failed to reject $H_0$
\end{enumerate}

\vspace{0.5cm}

\subsection*{Question 9: Error Trade-off (3 points)}

What happens to the probability of Type II error ($\beta$) when you DECREASE the significance level ($\alpha$) from 0.05 to 0.01?

\begin{enumerate}[label=\Alph*)]
\item $\beta$ decreases; being more conservative reduces all types of errors
\item $\beta$ stays the same; Type I and Type II errors are independent
\item $\beta$ becomes undefined; we can only control one type of error at a time
\item $\beta$ increases; making it harder to reject $H_0$ increases the chance of missing a true effect
\end{enumerate}

\vspace{0.5cm}

\subsection*{Question 10: Statistical Power (2 points)}

What is statistical power, and why is it important?

\begin{enumerate}[label=\Alph*)]
\item Power = $1 - \alpha$; it's the probability of correctly accepting a true null hypothesis
\item Power = $1 - \beta$; it's the probability of correctly rejecting a false null hypothesis (detecting a true effect)
\item Power = $\alpha + \beta$; it measures the total probability of making any error
\item Power = sample size / population size; larger samples have more power
\end{enumerate}

\section*{Common Mistakes to Avoid}

\begin{itemize}
\item \textbf{Hypotheses:} Confusing $H_0$ and $H_a$; using wrong tail (one-sided vs. two-sided)
\item \textbf{P-values:} Misinterpreting p-value as probability that $H_0$ is true
\item \textbf{Decision Rule:} Rejecting when p-value $> \alpha$, or failing to reject when p-value $< \alpha$
\item \textbf{Errors:} Confusing Type I ($\alpha$) and Type II ($\beta$) errors
\item \textbf{R Code:} Using wrong \texttt{alternative} parameter (``greater'', ``less'', ``two.sided'')
\end{itemize}

\section*{Key Formulas}

\textbf{One-sample t-statistic:}
$$t = \frac{\bar{x} - \mu_0}{s / \sqrt{n}}$$

\textbf{Two-sample t-statistic (equal variances):}
$$t = \frac{\bar{x}_1 - \bar{x}_2}{s_p\sqrt{\frac{1}{n_1} + \frac{1}{n_2}}}$$

\textbf{Decision Rule:}
\begin{itemize}
\item Reject $H_0$ if p-value $< \alpha$
\item Fail to reject $H_0$ if p-value $\geq \alpha$
\end{itemize}

\textbf{Relationships:}
\begin{itemize}
\item Type I Error: $\Pr(\text{Reject } H_0 \mid H_0 \text{ true}) = \alpha$
\item Type II Error: $\Pr(\text{Fail to reject } H_0 \mid H_0 \text{ false}) = \beta$
\item Power: $1 - \beta = \Pr(\text{Reject } H_0 \mid H_0 \text{ false})$
\end{itemize}
