=== SLIDE 16 ===
The Rules of Regular Expressions
Regular expressions consist of the following components:

literal characters: they are matched by a single character
character class: they are matched by a number of characters
anchors and quantifiers: they are used to operate on literal characters or character classes

=== SLIDE 17 ===
The Rules of Regular Expressions
Literal characters matching:
Most characters (all letters and digits) are regular expressions that match themselves
The period (.) matches any single character
Many punctuation marks are regular expression anchors or quantifiers, such as . ^ $ + ? * ( ) [ ] { } | \. These symbols are also called metacharacter 
Any metacharacter must always be preceded by a backslash to retain their literal meaning in regular expressions
When a regular expression is used in R , two backslash characters are needed to precede the modifiers in order to retain their normal meaning

=== SLIDE 18 ===
The Rules of Regular Expressions
A character class is a list of characters enclosed between []
A character class matches any single character in that list. For example, [ad1] matches letters a, or d, or digit 1
If the first character of the list is the caret (^), it matches any character not in the list. For example, [^abc] matches anything except the characters a, b, or c
A range of characters may be specified by giving the first and last characters, separated by a hyphen. For example, [a-d]
A range of digits may be specified by giving the first and last digits, separated by a hyphen. For example, [2-5] 
Special characters (metacharacters) do not need a backslash when used in a character class

=== SLIDE 19 ===
The Rules of Regular Expressions
An anchor does not match any specific character, but only matches a position within a text string, such as word boundary, a place between characters
The caret (^) and the dollar sign ($) match the empty string at the beginning and end of a line
The symbols \< and \> match the empty string at the beginning and end of a word

=== SLIDE 20 ===
The Rules of Regular Expressions
A regular expression may be followed by one of several repetition quantifiers
?:  matches 0 or 1 occurrences of preceding item
*: matches 0 or more occurrences of preceding item
+: matches 1 or more occurrences of preceding item
{n}: matches exactly n occurrences of preceding item
{n,}: matches at least n occurrences of preceding item
{n,m}: matches between n and m occurrences of preceding item

=== SLIDE 21 ===
The Rules of Regular Expressions
Two regular expressions may be joined by the infix operator |. This is referred to as alternation
The resulting regular expression from the alternation matches any string matching either sub-expression. For example, 123|789 matches either the string 123 or 789
Alternation does not work inside character classes, where | has its literal meaning

=== SLIDE 22 ===
The Rules of Regular Expressions
Here are some examples of using regular expressions:
a string with one letter, one digit, and followed by 3 or more letters: [a-zA-Z][0-9][a-zA-Z]{3,}
three consecutive occurrences of the string abc or def and repeated twice: (abc|def){2}
a pdf file with all letters as its file name: 
	^[a-zA-Z]+\\.pdf$

Splitting the Elements of a Character Vector
strsplit: split the elements of a character vector into substrings according to the matches to substring within them
x: A character vector, each element of which is to be split
split: A character vector containing regular expression (s) (unless fixed = TRUE) to use for splitting
fixed: A logical value. If it is TRUE and the function will match the split argument exactly
The result returned from the strsplit function is a list with the same length as argument x. The i_th element of the result contains the vector of splits of x[i]

Search a Pattern: grep and grepl
grep, grepl: search for matches of a given regular expression within a character vector
Here are the common arguments of these two functions:
pattern: a character string containing a regular expression to be matched in the given character
x: A character vector where matches are sought
ignore.case: A logical value. The default value is FALSE
fixed: A logical value. The default value is FALSE. If it is set to TRUE, the pattern is a string to be matched “as is”
