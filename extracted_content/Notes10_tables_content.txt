=== SLIDE 13 ===
Chi-squared Test
The χ2 test for independence evaluates whether or not there is an association between two categorical variables 
For example smoking status (nonsmoker, smoker, heavy smoker) and lung disease status (no disease, clinical signs of disease, disease) 
The Chi-Squared test for independence is a formal statistical procedure for determining whether or not an association suggested by an observed pattern in the data can be attributable to sampling variation alone.

=== SLIDE 14 ===
Properties of χ2 Distributions
Unlike t and Z distributions, but like F distributions, χ2 density curves are defined only on the positive real line 
Chi-squared distributions are not symmetric, they are right skewed.
Like all density curves, chi-squared curves never cross the x-axis and the total area under the curve is 1 
There are many chi-squared distributions. Each one is indexed by a single positive integer called degrees of freedom (df). Denoted either by df or m.

Paired Proportions
Common study-design in observational studies scientists often control for confounding by matching individuals that are similar with respect to values of confounding variables (e.g. age, BMI)
Also, one can take two dichotomous measurements on the same person under two different treatments (crossover designs), or pre and post treatment. 
These result in paired binary data.

=== SLIDE 33 ===
Paired Proportions – McNemar’s Test
Data from matched pairs are dependent.
Four possible outcome counts:
Number of pairs in which both are responders (nA)
Number of pairs in which first individual responds and second does not (nB)
Number of pairs in which the second individual responds and first does not (nC)
Number of pairs in which both do not respond (nD)

=== SLIDE 34 ===
McNemar’s Test
Concordant pairs are noninformative about response-exposure association.
Discordant pairs (one member of pair exposed one not) are informative about association.
Need sufficiently large number of discordant pairs(rule of thumb: nB+nC > 20)
Evidence of association if nB is a lot bigger than nC

=== SLIDE 43 ===
Simpson’s Paradox
Illustrates the importance of analyzing multiple 2 × 2 tables instead of analysis of a single 2 × 2 table 
The paradox states that the pattern between X and Y can be substantially changed, even completely reversed, when the data set is partitioned according to a third variable C 
See book for examples.

=== SLIDE 44 ===
Effect Modification
A population is stratified according to disjoint subgroups 
Denote the stratifying variable by C. Each individual belongs to one, and only one, of the groups 
If a disease-exposure relationship varies for the different groups, then C is said to be an effect modifier of exposure 
Example: Coffee/MI – if the effect of coffee consumption on MI is different for S than for NS, then smoking status is an effect modifier of coffee consumption 
Epidemiologists use the term effect modification while statisticians call this an interaction

=== SLIDE 45 ===
Confounding
A confounding variable is a variable that is related to both the outcome (e.g., disease) and predictor (e.g., exposure) AND is not on the causal pathway of disease 
For example, a 2 × 2 analysis of alcohol consumption (“exposure”) and lung cancer (“disease”) may find an association 
But smoking is known to act as a confounder so we may not see an association between alcohol and lung cancer among smokers or among nonsmokers

=== SLIDE 46 ===
Analyzing Multiple 2 × 2 Tables
Two key issues in the statistical analysis of multiple 2 × 2 tables 
1. Is it appropriate to pool information across strata and obtain a single estimate of a common effect measure? For instance, is it reasonable to estimate a common odds ratio, risk ratio, or risk difference? 
2. If it is appropriate to estimate an overall common effect measure, then how do we define such an estimator? If it is not appropriate to pool information across strata, then what inferences can we make?

=== SLIDE 47 ===
Case 1: Effect Modification
Effect modification (also called interaction): the X-Y association changes across levels of C 
Before pooling information across 2 × 2 tables, we must rule out effect modification by establishing that the population ORs are the same across subgroups 
If they aren’t, it doesn’t make sense to pool themIn this case we get separate inferences for ORj for j = 1,2,...,g where g denotes the total number of groups (the number of 2 × 2 tables)

=== SLIDE 48 ===
Case 1: Effect modification
In the coffee/MI example, if smoking status were an effect modifier then we would report point estimates and confidence intervals separately for smokers (ORS) and nonsmokers (ORN S ) using the methods presented earlier.
It would not make sense to pool these two estimates and then report inferences for a common effect of coffee consumption because these two odds ratios characterize different magnitudes of effect.

=== SLIDE 49 ===
Case 2: No Effect Modification
If no effect modification is present then there is homogeneity of odds ratios. 
Each 2 × 2 table provides an estimate of the same OR Can pool the information across the g, 2 × 2 tables to estimate the single population OR.
So the issues that remain are 
How do we test for homogeneity?How do we get an estimate of a common odds ratio?

=== SLIDE 53 ===
Steps for Data Analysis
Identify the g groups of the confounding variable 
Create g, 2 × 2 tables – one for each grp 
Test for homogeneity of odds ratios across groups 
H0 : all ORj's are equal 
Ha : at least one difference 
If H0 is rejected, there is evidence of effect modification. Report inferences separately for each grp ⇒ get point estimates and CIs separately for each 2 × 2 table 
If Ho is not rejected, then estimate the common OR using the adjusted logit or MH method. The CI can be used to test Ho :OR=1 in the usual way.
