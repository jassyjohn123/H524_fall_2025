Multiple Correlation
Multiple correlation measures the degree of association between Y and  (X₁, X₂, ..., Xₖ).
Helps to understand how well (X₁, X₂, ..., Xₖ) collectively explain the variability in Y.
SSY: Total Sum of Squares (total variance in Y)
SSE: Sum of Squared Errors (variance in Y not explained by independent variables)
Multiple R2 represents the proportion of the total variation in Y that is explained by (X₁, X₂, ..., Xₖ).

=== SLIDE 3 ===
Multiple Correlation
0: No linear relationship between Y and  (X₁, X₂, ..., Xₖ).
1: Perfect linear relationship
 Higher R value indicates (X₁, X₂, ..., Xₖ) collectively explain a significant proportion of variance in Y.

=== SLIDE 24 ===
Testing for Interaction Effect
If interactions are being considered, hypothesis tests for the corresponding interaction coefficient should be evaluated first. 

If interaction effects are non-significant, the model should be re-fit without the interaction.

If the interaction is significant, the data should be stratified by one of the variables, and the analyses need to be done separately within each subgroup.

=== SLIDE 28 ===
Evaluating the Confounding Effect
To check if Z is a confounder, include it in the model.

If adding Z changes the main effect estimate significantly, treat Z as a confounder, even if Z is not statistically significant.

If adding Z doesn’t change the main effect much, you may or may not include Z in the model.

If Z isn’t a confounder, don’t include it in the model, even if it changes the estimate or is statistically significant.

=== SLIDE 32 ===
Evaluating the Confounding Effect
How to choose potential confounders?
Philosophically: Include variables known to be related to both the outcome (Y) and the predictor (X).
Statistically: Without enough prior info, you could include all possible variables "just to be safe," but:
This can increase missing data and reduce the sample size.
A large model with many nonsignificant variables complicates prediction.

=== SLIDE 33 ===
Evaluating the Confounding Effect
To see if C is a confounder in the Y vs. X relationship, check how the X coefficient changes after adjusting for C.

If ꞵ1changes by 10%-15% from the unadjusted to adjusted model, C is likely a confounder.

Just because Y and C are correlated doesn’t mean C is a confounder. C must be related to both Y and X to be a confounder.

=== SLIDE 34 ===
Summary
Multiple Correlation: Assesses how well multiple independent variables together predict a dependent variable.
Partial Correlation: Measures the relationship between two variables while controlling for others.
Testing Interaction: Add an interaction term (X * Z) to the model; significance of this term shows if the effect of X on Y depends on Z.
Evaluating Confounding: Compare the X coefficient before and after adjusting for the potential confounder. A 10%-15% change indicates a confounder.
