=== SLIDE 4 ===
Create ggplot
ggplot(data = mpg) + geom_point(mapping = aes(x = displ, y = hwy)) 
First argument is dataset
Basic template is:
ggplot(data = <DATA>) + <GEOM_FUNCTION>(mapping = aes(<MAPPINGS>))

=== SLIDE 5 ===
Aesthetic Mappings
You can convey information about your data by mapping aesthetics to variables in your dataset.
Add class to add “levels”
Try: ggplot(data = mpg) + geom_point(mapping = aes(x = displ, y = hwy, color = class))

=== SLIDE 6 ===
Aesthetic mapping
Could use size instead of class (perhaps not good for unordered variable)

ggplot(data = mpg) +
    geom_point(mapping = aes(x = displ, y = hwy, size = class))

Could use shape (only six at a time – note error)or alpha (transparency) as well

	ggplot(data = mpg) +
	   geom_point(mapping = aes(x = displ, y = hwy, shape = class))

=== SLIDE 7 ===
Aesthetic mapping
aes() - associate name of aesthetic with variable to display.
ggplot2 takes care of legend, tick marks, etc.
You can set aesthetic properties of geom manually.
Ex. Make all point in our plot blue:
ggplot(data = mpg) + geom_point(mapping = aes(x = displ, y = hwy), color = "blue") 
Note to set aesthetic manually the argument goes outside of aes.

=== SLIDE 8 ===
Manually set aesthetic
Pick value that makes sense for aesthetic
Name of color as character string
Size of point in mm
Shape as number
Ex:
mpg2 <- mpg %>%
    mutate(class.fct=factor(class))
ggplot(data = mpg2) +
    geom_point(mapping = aes(x = displ, y = hwy, shape=class.fct)) +
    scale_shape_manual(values=1:nlevels(mpg2$class.fct))

=== SLIDE 9 ===
Facets
One can add additional variables via aesthetics.
Another way is through facet, subplots that each display one subset of data.
Use facet_wrap() 
First argument if “formula” (~) followed by a variable name
Here “formula” is a data structure not equation
ggplot(data = mpg) + geom_point(mapping = aes(x = displ, y = hwy)) + facet_wrap(~ class, nrow = 2)

=== SLIDE 10 ===
Facets
Use facet_grid()
ggplot(data = mpg) + geom_point(mapping = aes(x = displ, y = hwy)) + facet_grid(drv ~ cyl) 
May use “.” instead of variable name (see class notes)

=== SLIDE 11 ===
Geom
Geom is a geometrical object that a plot uses. 
Bar charts use bar geoms, line charts use line geoms, boxplots use box geoms.
To change the geom, change the geom function
ggplot(data = mpg) + geom_point(mapping = aes(x = displ, y = hwy)) 
ggplot(data = mpg) + geom_smooth(mapping = aes(x = displ, y = hwy))

=== SLIDE 12 ===
Geom
Every geom function take a mapping argument.
Not every aesthetic works with every geom.
You can set the shape of a point but can’t set shape of a line.
Can set linetype of a line
geom_smooth() will draw a different line with a different linetype for each unique value of the variable 
ggplot(data = mpg) + geom_smooth(mapping = aes(x = displ, y = hwy, linetype = drv))

=== SLIDE 13 ===
Geoms
ggplot2 provides over 30 geoms (Google it)
Extension packages provide more
See ?geom_smooth

=== SLIDE 14 ===
geom_smooth()
Uses a single geometric object to display multiple rows of data.
Can set the group aesthetic to a categorical variable to draw multiple objects.

=== SLIDE 15 ===
Display multiple geoms
One can do:
ggplot(data = mpg) + geom_point(mapping = aes(x = displ, y = hwy)) + geom_smooth(mapping = aes(x = displ, y = hwy)) 
Or the simpler:
ggplot(data = mpg, mapping = aes(x = displ, y = hwy)) + geom_point() + geom_smooth()

=== SLIDE 16 ===
Display Multiple Geoms
If you place mappings in a geom, ggplot2 will treat them as local mapping for that layer.
These mappings will extend or overwrite the global mappings for that layer only.
ggplot(data = mpg, mapping = aes(x = displ, y = hwy)) + geom_point(mapping = aes(color = class)) + geom_smooth()

=== SLIDE 17 ===
Multiple Geoms
Can specify different data for each layer.
The local data argument in geom_smooth() overrides the global data argument in the ggplot() for that layer only.
ggplot(data = mpg, mapping = aes(x = displ, y = hwy)) + geom_point(mapping = aes(color = class)) + geom_smooth( data = filter(mpg, class == "subcompact"), se = FALSE )

=== SLIDE 18 ===
Statistical Transformations
Basic bar charts drawn with geom_bar()
Examine the diamonds dataset.
Includes price, carat, color, clarity and cut.
Note that geom_bar() plots count which is not part of the dataset.
Many graphs plot raw data (e.g. scatterplots) while other plot calculate new values.
Algorithms to calculate new values is called a stat.

=== SLIDE 19 ===
Statistical Transformations
E.g. For bar chart can substitute default stat of count with identity.
Can override default mapping from transformed variables to aesthetics.
E.g. Look at proportions instead of counts.
ggplot(data = diamonds) + geom_bar( mapping = aes(x = cut, y = ..prop.., group = 1) ) 
ggplot2 provides over 20 stats to use
See ggplot2 cheatsheet.
