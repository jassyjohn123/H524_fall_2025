=== SLIDE 1 ===
Tidyverse
Here we will learn about packages developed largely by Hadley Wickham 
The tidyverse packages include ggplot2, tibble, tidyr, readr, purrr, and dplyr packages. 
Packages can be installed with install.packages(“tidyverse”) and loaded with require(“tidyverse”)

=== SLIDE 2 ===
Tidyverse
These packages represent a relatively unified way of managing and visualizing data.
The packages can be seen as enhancements to “base” R functionality.
Overall, these packages allow one to use R typically without having to revert to using other packages such as SAS, Excel and others for data management, visualization, etc.

=== SLIDE 3 ===
Data.table
A “competitor” to tidyverse packages is data.table, which is (arguably) faster and more efficient, but is more cumbersome to use.
Tidyverse is already super fast (based on underlying C++ code) and very extensible and flexible.

=== SLIDE 4 ===
dplyr
The dplyr package is an extremely useful package for data management. 
It’s faster than base R, and more intuitive (arguably).
In the past, many would use an alternative package such as SAS to do data management and then R to do analysis.
With dplyr one can efficiently do the data management in R.

dplyr basics

=== SLIDE 21 ===
Alternative: double piping
a <- transmute(flights,
          gain = arr_delay - dep_delay,
          hours = air_time / 60,
          gain_per_hour = gain / hours
          )

b <- flights %>% mutate(
      gain = arr_delay - dep_delay,
      hours = air_time / 60,
      gain_per_hour = gain / hours
      ) %>%
    select(gain,hours,gain_per_hour)

identical(a,b)

=== SLIDE 22 ===
Can still use base R constructs
