\section{Introduction: When to Use Nonparametric Tests}

Parametric tests (t-tests, ANOVA) assume data are normally distributed. When this assumption is violated, use nonparametric tests instead.

\vspace{0.3cm}
\textbf{Use nonparametric tests when:}
\begin{itemize}
\item Data are significantly skewed
\item Extreme outliers are present
\item Small sample size (n < 20)
\item Ordinal data (pain scales, ratings)
\item Shapiro-Wilk test p-value < 0.05
\end{itemize}

\vspace{0.3cm}
\textbf{Quick Reference:}
\begin{center}
\small
\begin{tabular}{lll}
\toprule
\textbf{Scenario} & \textbf{Normal Data} & \textbf{Not Normal} \\
\midrule
One sample & t-test & Sign or Wilcoxon \\
Paired data & Paired t-test & Sign or Wilcoxon \\
Two groups & Two-sample t-test & Wilcoxon rank-sum \\
3+ groups & ANOVA & Kruskal-Wallis \\
\bottomrule
\end{tabular}
\end{center}

\section{Part 1: Checking Normality}

Always check normality before choosing your test.

\subsection{Exercise 1: Shapiro-Wilk Test}

The Shapiro-Wilk test checks if data are normally distributed.
\begin{itemize}
\item $H_0$: Data are normal
\item If $p \geq 0.05$: Use parametric test
\item If $p < 0.05$: Use nonparametric test
\end{itemize}

\begin{rcode}
# Generate example data
set.seed(524)
normal_data <- rnorm(30, mean=100, sd=15)
skewed_data <- rexp(30, rate=0.02)

# Check normality
shapiro.test(normal_data)
shapiro.test(skewed_data)

# Visual check (optional)
hist(normal_data, main="Normal Data", col="lightblue")
hist(skewed_data, main="Skewed Data", col="lightcoral")

# Q-Q plots
qqnorm(normal_data, main="Normal Data Q-Q Plot")
qqline(normal_data, col="red")

qqnorm(skewed_data, main="Skewed Data Q-Q Plot")
qqline(skewed_data, col="red")
\end{rcode}

\textbf{Questions:}
\begin{enumerate}
\item What is the p-value for \texttt{normal\_data}?
\item What is the p-value for \texttt{skewed\_data}?
\item For \texttt{normal\_data}, should you use parametric or nonparametric tests?
\item For \texttt{skewed\_data}, should you use parametric or nonparametric tests?
\end{enumerate}

\section{Part 2: Sign Test}

The sign test only uses the direction (+/-) of differences.

\subsection{Exercise 2: Sign Test for One Sample}

\textbf{Question:} Is median recovery time different from 7 days?

\begin{rcode}
# Recovery times (days)
recovery <- c(8, 5, 7, 10, 4, 9, 3, 12, 6, 11, 7)

# Hypothesized median
med0 <- 7

# Calculate differences
diff <- recovery - med0

# Count signs (ignoring zeros)
n_positive <- sum(diff > 0)
n_total <- sum(diff != 0)

cat("Positive differences:", n_positive, "\n")
cat("Total non-zero:", n_total, "\n")

# Sign test
binom.test(n_positive, n_total, p=0.5)
\end{rcode}

\textbf{Questions:}
\begin{enumerate}
\item How many positive differences are there?
\item How many total non-zero differences?
\item What is the p-value?
\item Is the median significantly different from 7 days?
\end{enumerate}

\section{Part 3: Wilcoxon Signed-Rank Test (Paired Data)}

Use for paired data when normality assumption is violated.

\subsection{Exercise 4: Blood Pressure Study}

\textbf{Research Question:} Does medication reduce blood pressure?

# Check normality of differences

shapiro.test(diff)

cat("Mean BP after:", mean(bp_after), "\n")
cat("Mean reduction:", mean(diff), "\n")
\end{rcode}

\textbf{Questions:}
\begin{enumerate}
\item What is the Shapiro-Wilk p-value for the differences? Is normality OK?
\item What is the Wilcoxon test p-value?
\item Is the difference significant at $\alpha = 0.05$?
\item Does the medication reduce blood pressure?
\item What is the mean reduction in blood pressure?
\end{enumerate}

\section{Part 5: Kruskal-Wallis Test (Three or More Groups)}

Use for comparing 3+ independent groups when normality is violated.

\subsection{Exercise 8: Pain Relief Comparison}

\textbf{Research Question:} Do three pain medications differ in effectiveness?

\begin{rcode}
# Pain relief scores (0-10 scale, higher = better)
drug_A <- c(3, 4, 5, 4, 3, 5, 4)
drug_B <- c(5, 6, 7, 6, 5, 7, 6)
drug_C <- c(7, 8, 9, 8, 7, 9, 8)

# Combine data
pain_scores <- c(drug_A, drug_B, drug_C)
drug <- factor(rep(c("A", "B", "C"), each=7))

# Check normality for each group
shapiro.test(drug_A)
shapiro.test(drug_B)
shapiro.test(drug_C)

# Visualize
boxplot(pain_scores ~ drug,
        xlab="Drug",
        ylab="Pain Relief Score",
        main="Pain Relief by Drug",
        col=c("lightblue", "lightgreen", "lightyellow"))

# Kruskal-Wallis test
kruskal.test(pain_scores ~ drug)

# Post-hoc pairwise comparisons
pairwise.wilcox.test(pain_scores, drug, p.adjust.method="bonferroni")

# Summary statistics
tapply(pain_scores, drug, median)
\end{rcode}

\textbf{Questions:}
\begin{enumerate}
\item What is the Kruskal-Wallis p-value?
\item Do the drugs differ significantly overall at $\alpha = 0.05$?
\item According to the post-hoc tests, which specific pairs of drugs differ significantly?
\item Which drug appears most effective based on median scores?
\item Which drug appears least effective?
\end{enumerate}

\section{Part 6: Comparing Parametric vs Nonparametric}

\subsection{Exercise 9: When Both Tests Apply}

Sometimes data are borderline normal. Let's compare both approaches.

\begin{rcode}
# Blood pressure data (from Exercise 4)
bp_before <- c(145, 138, 150, 142, 156, 148, 140, 152)
bp_after <- c(138, 135, 142, 140, 148, 145, 138, 146)

# Check normality
diff <- bp_before - bp_after
shapiro.test(diff)

# Parametric: Paired t-test
t_result <- t.test(bp_before, bp_after, paired=TRUE)
cat("Paired t-test p-value:", t_result$p.value, "\n")

# Nonparametric: Wilcoxon
w_result <- wilcox.test(bp_before, bp_after, paired=TRUE)
cat("Wilcoxon p-value:", w_result$p.value, "\n")

# Compare
cat("\nBoth tests significant? Compare p-values to 0.05\n")
\end{rcode}

\textbf{Questions:}
\begin{enumerate}
\item Is the normality assumption met (p $\geq$ 0.05)?
\item Which test gives a smaller p-value?
\item Do both tests reach the same conclusion (significant or not)?
\item When data are borderline normal, which test is safer to use?
\end{enumerate}

\section{Decision Guide Summary}

\textbf{Step 1: Check normality}
\begin{itemize}
\item Use \texttt{shapiro.test()}
\item If $p \geq 0.05$: Normal OK $\rightarrow$ Use parametric
\item If $p < 0.05$: Not normal $\rightarrow$ Use nonparametric
\end{itemize}

\textbf{Step 2: Choose test}
\begin{itemize}
\item \textbf{One sample or paired:} Sign test or \texttt{wilcox.test()}
\item \textbf{Two groups:} \texttt{wilcox.test(group1, group2)}
\item \textbf{3+ groups:} \texttt{kruskal.test(outcome \textasciitilde{} group)}
\item \textbf{Post-hoc:} \texttt{pairwise.wilcox.test()}
\end{itemize}

\textbf{Step 3: Interpret}
\begin{itemize}
\item $p < 0.05$: Significant difference
\item $p \geq 0.05$: No significant difference
\end{itemize}

\section{Key Takeaways}

\begin{enumerate}
\item \textbf{Always check normality first} with Shapiro-Wilk test
\item \textbf{Nonparametric tests are robust} to outliers and skewness
\item \textbf{Wilcoxon tests} are the nonparametric versions of t-tests
\item \textbf{Kruskal-Wallis} is the nonparametric version of ANOVA
\item \textbf{When in doubt}, use nonparametric (safer choice)
\item \textbf{For ordinal data}, ALWAYS use nonparametric
\item \textbf{Follow up Kruskal-Wallis} with post-hoc tests if significant
\end{enumerate}
