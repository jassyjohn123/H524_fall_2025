## Compiling PDFs

The .tex files need to be compiled to create PDF documents for distribution to students.

### Option 1: Using pdflatex (Recommended)
```bash
cd Final_Project
pdflatex final_project_guidelines.tex
pdflatex grading_rubric.tex
```

### Option 2: Using Overleaf
1. Upload the .tex files to Overleaf (https://www.overleaf.com)
2. Compile online
3. Download the resulting PDFs

### Option 3: Using TeXShop (macOS)
1. Open .tex files in TeXShop
2. Click "Typeset" button
3. PDFs will be generated automatically

### Option 4: Using MiKTeX (Windows)
1. Install MiKTeX if not already installed
2. Open .tex files in TeXworks
3. Select pdfLaTeX from dropdown
4. Click the green "Typeset" button

## Quick Start for Students

1. Read final_project_guidelines.md thoroughly (or .pdf if provided)
2. Form teams of 4-5 students by Week 4
3. Use proposal_template.md to draft your 150-word proposal (due Week 5)
4. Use dataset_suggestions.md to find appropriate data
5. Use prompt_log_template.md to document AI interactions throughout
6. Sign up for presentation slot using the signup sheet

## Project Timeline

- **Week 4:** Teams formed
- **Week 5:** Proposal due (Sunday 11:59 PM)
- **Week 6-7:** Class discussions and feedback
- **Week 8-9:** Work on project
- **Week 10:** Presentations + all materials due

## Key Requirements

- Teams: 4-5 students
- Statistical method: Choose ONE (chi-square, correlation, regression, t-test, ANOVA, bootstrap)
- AI tools: Must compare at least 2 (ChatGPT, Claude, Gemini, Copilot, etc.)
- Deliverables: 10-min presentation, 2-page write-up, prompt log, data/code
- Grading: 100 points total
